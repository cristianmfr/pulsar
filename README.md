# Pulsar

**A sleek, refined dark theme for deep focus.**

Pulsar is inspired by the default Cursor IDE aesthetic — near-black backgrounds, soft pastel accents, and a carefully balanced syntax palette. Every color was tuned for legibility and visual comfort, so your eyes stay relaxed even after hours of coding.

## ✨ Highlights

- **Minimal & distraction-free** — deep `#141414` / `#181818` backgrounds with subtle, low-contrast UI borders that let your code take center stage
- **Soft pastel syntax palette** — mint keywords, peach types, lavender properties, pink strings, and golden functions, all easy on the eyes
- **Semantic highlighting support** — fine-tuned token colors for TypeScript, JavaScript, Python, C/C++, Rust, PHP, Go, Java, Markdown, and more
- **Consistent everywhere** — terminal ANSI colors, diff views, merge conflicts, and Git decorations all follow the same palette

## 📦 Installation

1. Open the **Extensions** view (`Ctrl+Shift+X` / `Cmd+Shift+X`)
2. Search for **Pulsar**
3. Click **Install**
4. Select the theme via `Ctrl+K Ctrl+T` / `Cmd+K Cmd+T` → **Pulsar**
